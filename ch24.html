Part A. Strang, Introduction to Linear Algebra, 4th ed., Ch. 1 to 7

Chapter 1. Introduction to Vectors

1.1 Vectors and Linear Combinations

  • A linear combination of v and w is cv + dw (c, d any numbers).
  • All combinations of one nonzero vector: a line through 0. Of two independent vectors in R^3: a plane through 0. Of three independent vectors in R^3: all of R^3.
  • Vectors are added component by component, and a scalar multiplies every component.

1.2 Lengths and Dot Products (LA1)

  • Dot product v·w = v1 w1 + v2 w2 + ... + vn wn. It is a number, and v·w = w·v.
  • Length ||v|| = √(v·v). Unit vector u = v/||v||.
  • v and w are perpendicular exactly when v·w = 0.
  • Angle: cos θ = v·w / (||v|| ||w||).
  • Schwarz inequality: |v·w| ≤ ||v|| ||w||. Triangle inequality: ||v + w|| ≤ ||v|| + ||w||.

1.3 Matrices

  • Ax is a combination of the columns of A (column picture). Each entry of Ax is a row of A dotted with x (row picture).
  • Columns are independent when Ax = 0 only for x = 0. Otherwise dependent.

Chapter 2. Solving Linear Equations

2.1 Vectors and Linear Equations

  • Row picture: each equation is a line (2D) or plane (3D), and the solution is where they meet. Column picture: find the combination of columns that equals b.
  • Matrix form Ax = b. The identity I has Ix = x.

2.2 The Idea of Elimination (LA3)

  • Pivot: the first nonzero entry in the row that does the elimination. Multiplier ℓ_ij = (entry to eliminate)/(pivot).
  • Goal: upper triangular system Ux = c, then back substitution from the bottom.
  • Breakdown: a zero in a pivot position. Temporary if a lower row can be exchanged in. Permanent if not: the matrix is singular, and the system has no solution or infinitely many.

2.3 Elimination Using Matrices

  • Elimination matrix E_ij subtracts ℓ times row j from row i. Permutation matrix P_ij exchanges rows i and j.
  • Augmented matrix [A b]. Elimination gives EA = U.

2.4 Rules for Matrix Operations

  • (AB)_ij = (row i of A)·(column j of B). Sizes: (m by n)(n by p) = (m by p).
  • AB ≠ BA in general. But (AB)C = A(BC), A(B + C) = AB + AC.
  • Four views of AB: entries (dot products), A times each column of B, each row of A times B, sum of (columns of A) times (rows of B).
  • Block multiplication works when the block sizes fit.

2.5 Inverse Matrices (LA4, LA5)

  • A^-1 A = I = A A^-1. A has an inverse exactly when it has n pivots (row exchanges allowed), when det A ≠ 0, and when Ax = 0 has only x = 0.
  • (AB)^-1 = B^-1 A^-1 (reverse order). (A^T)^-1 = (A^-1)^T.
  • 2 by 2: [a b; c d]^-1 = (1/(ad - bc)) [d -b; -c a].
  • Gauss-Jordan: reduce [A I] to [I A^-1].

2.6 Elimination = Factorization: A = LU (LA3)

  • A = LU: L lower triangular with 1s on the diagonal and the multipliers ℓ_ij below it. U upper triangular with the pivots on the diagonal.
  • A = LDU splits the pivots into a diagonal D (so U has 1s on its diagonal).
  • To solve Ax = b: Lc = b (forward), then Ux = c (backward).
  • Elimination on an n by n matrix costs about n^3/3 multiply-subtract steps. Each right side costs about n^2.

2.7 Transposes and Permutations

  • (A^T)_ij = A_ji. (AB)^T = B^T A^T. (A^-1)^T = (A^T)^-1.
  • Symmetric: S^T = S. R^T R is always symmetric (and so is R R^T).
  • (Ax)·y = x·(A^T y).
  • Permutation matrix: rows of I in some order. P^-1 = P^T. There are n! of them for size n.
  • With row exchanges: PA = LU. A symmetric matrix that needs no row exchanges factors as S = L D L^T. (Some symmetric matrices do need a row exchange, for example [0 1; 1 0].)

Chapter 3. Vector Spaces and Subspaces

3.1 Spaces of Vectors (LA6)

  • A vector space is closed under addition and scalar multiplication. Examples: R^n, M (all 2 by 2 matrices, dimension 4), F (functions), Z (only the zero vector).
  • A subspace is a subset that is itself a vector space: closed under + and scalar ×, so it contains 0. [HIGH: "is this a subspace / linear"]
  • Column space C(A): all combinations of the columns = all Ax. A subspace of R^m.
  • Ax = b is solvable exactly when b is in C(A).
  • The span of some vectors: all their combinations.

3.2 The Nullspace of A: Solving Ax = 0 (LA7)

  • Nullspace N(A) = all x with Ax = 0. A subspace of R^n. (Also called the kernel.) [HIGH: applicants lost time on this word]
  • Pivot columns and free columns. Free variables can be anything.
  • Special solutions: set one free variable to 1, the others to 0, solve for the pivot variables. There are n - r of them, and they are a basis of N(A).
  • If n > m (more unknowns than equations), Ax = 0 has a nonzero solution.

3.3 The Rank and the Row Reduced Form (LA7, LA8)

  • Rank r = number of pivots. [HIGH]
  • Reduced row echelon form R = rref(A): pivots are 1, with zeros above and below them.
  • If R = [I F; 0 0], the nullspace matrix is N = [-F; I] (when the pivot columns come first; otherwise reorder the rows of N to match the columns. Example: LA9 has pivots in columns 1 and 3, so build the special solutions directly).
  • Rank one matrices are (column)(row): A = u v^T.

3.4 The Complete Solution to Ax = b (LA9)

  • x = x_p + x_n: one particular solution plus any nullspace vector.
  • Particular solution: set the free variables to 0.
  • Solvability: every zero row of R must have a zero on the right side.
  • Four cases:
Case Ax = b has
r = m = n (square, invertible) exactly 1 solution
r = m < n (full row rank) infinitely many solutions
r = n < m (full column rank) 0 or 1 solution
r < m and r < n 0 or infinitely many

3.5 Independence, Basis and Dimension (LA2)

  • Independent: the only combination giving 0 is the zero combination. Columns of A are independent exactly when N(A) = {0}, exactly when r = n. [HIGH]
  • Any n + 1 vectors in R^n are dependent.
  • Basis: independent vectors that span the space. Dimension: the number of vectors in any basis (every basis has the same number).
  • n vectors in R^n are a basis exactly when the n by n matrix with those columns is invertible.

3.6 Dimensions of the Four Subspaces (LA10)

  • The four fundamental subspaces of an m by n matrix of rank r: [HIGH]
Subspace Inside Dimension Basis from
Column space C(A) R^m r pivot columns of A
Row space C(A^T) R^n r nonzero rows of R (or U)
Nullspace N(A) R^n n - r special solutions
Left nullspace N(A^T) R^m m - r last m - r rows of E (where EA = R)
  • Row rank = column rank (rank of A^T = rank of A).
  • Elimination keeps the row space and the nullspace but changes the column space.

Chapter 4. Orthogonality

4.1 Orthogonality of the Four Subspaces (LA11)

  • Subspaces V and W are orthogonal when every v in V is perpendicular to every w in W.
  • N(A) ⊥ C(A^T) in R^n, and N(A^T) ⊥ C(A) in R^m. They are orthogonal complements: dimensions add to n (and to m). [HIGH]
  • Orthogonal complement V⊥ = all vectors perpendicular to V.
  • Every x in R^n splits as x = x_row + x_null.

4.2 Projections (LA12, LA13)

  • Onto a line through a: p = (a·b / a·a) a, P = a a^T / (a^T a). [HIGH]
  • Onto the column space of A (independent columns): A^T A x̂ = A^T b, p = A x̂, P = A (A^T A)^-1 A^T. [HIGH]
  • P^2 = P and P^T = P. The error e = b - p is perpendicular to the subspace.
  • I - P projects onto the orthogonal complement.
  • A^T A is invertible exactly when A has independent columns.

4.3 Least Squares Approximations (LA13)

  • When Ax = b has no solution, minimise ||Ax - b||^2. The answer x̂ solves the normal equations A^T A x̂ = A^T b. [HIGH]
  • Best line C + Dt through (t_i, b_i): A has columns (1, ..., 1) and (t_1, ..., t_m). A^T A = [m, Σt_i; Σt_i, Σt_i^2] and A^T b = (Σb_i, Σt_i b_i).
  • With a constant term in the model, the errors add up to 0.
  • The calculus way (set partial derivatives to 0) gives the same normal equations.

4.4 Orthogonal Bases and Gram-Schmidt (LA14, LA15)

  • Orthonormal vectors: q_i·q_j = 0 for i ≠ j and = 1 for i = j. Then Q^T Q = I.
  • A square Q with orthonormal columns is an orthogonal matrix: Q^T = Q^-1. Examples: rotations, permutations, reflections I - 2uu^T with u a unit vector (u^T u = 1). [HIGH]
  • Q keeps lengths and angles: ||Qx|| = ||x||, (Qx)·(Qy) = x·y.
  • With orthonormal columns: x̂ = Q^T b, p = Q Q^T b.
  • Gram-Schmidt: A = a. B = b - (A·b / A·A) A. C = c - (A·c / A·A) A - (B·c / B·B) B. Then q1 = A/||A||, q2 = B/||B||, q3 = C/||C||. [HIGH]
  • A = QR, with R = Q^T A upper triangular.

Chapter 5. Determinants

5.1 The Properties of Determinants (LA16)

  • The ten properties (state them in this order): [HIGH]
    1. det I = 1.
    2. Exchanging two rows changes the sign.
    3. det is linear in each row separately (multiply a row by t: det times t; add a vector to one row: dets add).
    4. Two equal rows give det = 0.
    5. Subtracting a multiple of one row from another does not change det.
    6. A row of zeros gives det = 0.
    7. Triangular matrix: det = product of the diagonal entries.
    8. A is singular exactly when det A = 0.
    9. det(AB) = det A · det B.
    10. det(A^T) = det A.
  • Consequences: det(A^-1) = 1/det A, det(cA) = c^n det A (n by n), det A = ± (product of the pivots).

5.2 Permutations and Cofactors (LA17, LA8)

  • 2 by 2: ad - bc. 3 by 3 by cofactors (or the diagonal rule for 3 by 3 only).
  • Cofactor C_ij = (-1)^(i+j) det M_ij (M_ij = A without row i and column j). Expansion: det A = a_i1 C_i1 + ... + a_in C_in along any row i (or any column).
  • Big formula: a sum of n! terms, one for each permutation, each with sign ±1.

5.3 Cramer's Rule, Inverses, and Volumes (LA17, LA18)

  • Cramer's rule: x_j = det B_j / det A, where B_j is A with column j replaced by b.
  • A^-1 = C^T / det A (C = cofactor matrix; note the transpose).
  • |det A| = area of the parallelogram (2D) or volume of the box (3D) built on the rows. Triangle = half the parallelogram. Tetrahedron = one sixth of the box.
  • Cross product u × v = det [i j k; u1 u2 u3; v1 v2 v3]. It is perpendicular to u and v, ||u × v|| = ||u|| ||v|| |sin θ|, and u × v = -(v × u).
  • Triple product (u × v)·w = det of the 3 by 3 matrix with rows u, v, w.

Chapter 6. Eigenvalues and Eigenvectors

6.1 Introduction to Eigenvalues (LA19, LA20)

  • Ax = λx with x ≠ 0. Eigenvalues solve det(A - λI) = 0. Eigenvectors span N(A - λI). [HIGH]
  • Sum of eigenvalues = trace (sum of the diagonal). Product = det A. [HIGH]
  • Triangular matrix: eigenvalues are the diagonal entries.
  • A^k x = λ^k x. A^-1 x = (1/λ) x. (A + cI)x = (λ + c)x.
  • A is singular exactly when λ = 0 is an eigenvalue.
  • Projection: λ = 1 and 0. Reflection: λ = 1 and -1. Rotation by 90 degrees: λ = ±i.
  • Eigenvalues of A + B and AB are usually not sums or products of eigenvalues of A and B.
  • Markov matrix (positive entries, columns add to 1): λ = 1 is an eigenvalue, and its eigenvector is the steady state. The other |λ| < 1.

6.2 Diagonalizing a Matrix (LA19, LA20, LA5)

  • With n independent eigenvectors in the columns of S: A = S Λ S^-1, Λ = diag(λ1, ..., λn). (Strang's 5th edition writes X instead of S.) [HIGH]
  • A^k = S Λ^k S^-1. [HIGH]
  • Distinct eigenvalues give independent eigenvectors, so A is diagonalizable. Repeated eigenvalues may not (example [α 1; 0 α]).
  • Difference equation u_(k+1) = A u_k: write u_0 = c1 x1 + ... + cn xn, then u_k = c1 λ1^k x1 + ... + cn λn^k xn.
  • Fibonacci: λ = (1 ± √5)/2.
  • Cayley-Hamilton: A satisfies its own characteristic equation. For 2 by 2: A^2 - (tr A) A + (det A) I = 0. [HIGH in old lists]

6.3 Applications to Differential Equations (C25)

  • du/dt = Au: pure solutions e^(λt) x. General: u(t) = c1 e^(λ1 t) x1 + ... + cn e^(λn t) xn.
  • e^(At) = I + At + (At)^2/2! + ... = S e^(Λt) S^-1 when A is diagonalizable.
  • Stability: u(t) → 0 when every eigenvalue has negative real part. For 2 by 2: trace < 0 and det > 0.
  • y'' + B y' + C y = 0 becomes a system with u = (y, y') and matrix [0 1; -C -B].

6.4 Symmetric Matrices (LA22)

  • Spectral theorem: a real symmetric matrix has real eigenvalues and orthonormal eigenvectors: A = Q Λ Q^T. [HIGH]
  • A = λ1 q1 q1^T + ... + λn qn qn^T (sum of rank one projections).
  • Eigenvectors for different eigenvalues of a symmetric matrix are orthogonal (proof: λ x·y = (Ax)·y = x·(Ay) = μ x·y).
  • For symmetric A (elimination with no row exchanges): the number of positive pivots equals the number of positive eigenvalues (same for negative). It is about counts, not pairs: [1 2; 2 1] has pivots 1 and -3 and eigenvalues 3 and -1.

6.5 Positive Definite Matrices (LA23)

  • For a symmetric A, these five tests are equivalent (each one means positive definite): [HIGH]
    1. All n pivots are positive.
    2. All n upper left determinants are positive.
    3. All n eigenvalues are positive.
    4. x^T A x > 0 for every x ≠ 0 (the "energy").
    5. A = R^T R for a matrix R with independent columns.
  • 2 by 2 [a b; b c]: positive definite exactly when a > 0 and ac - b^2 > 0.
  • Semidefinite (symmetric A): all eigenvalues ≥ 0, which is the same as x^T A x ≥ 0 for every x, and the same as A = R^T R for some R (columns may be dependent). Warning: upper-left determinants ≥ 0 is NOT enough. Example: A = [0 0; 0 -1] has upper-left determinants 0 and 0, but it has eigenvalue -1, and x = (0, 1) gives x^T A x = -1.
  • Meaning: f(x) = x^T A x is a bowl with its minimum at 0. It is the matrix second derivative test. The level set x^T A x = 1 is an ellipse whose axes are the eigenvectors, with half-lengths 1/√λ.

6.6 Similar Matrices (LA21)

  • B = M^-1 A M is similar to A. Similar matrices have the same eigenvalues (same trace, same det). Eigenvectors change: x becomes M^-1 x.
  • Jordan form: every square matrix is similar to a Jordan matrix J (blocks with λ on the diagonal and 1s just above it). One eigenvector per block. A is diagonalizable exactly when every block is 1 by 1.

6.7 Singular Value Decomposition (SVD) (LA24)

  • A = U Σ V^T for every m by n matrix. U (m by m) and V (n by n) orthogonal, Σ has σ1 ≥ σ2 ≥ ... ≥ 0 on its diagonal.
  • A v_i = σ_i u_i. σ_i^2 = eigenvalues of A^T A (and of A A^T). The v's are eigenvectors of A^T A, the u's of A A^T.
  • v1 to vr: orthonormal basis of the row space. u1 to ur: of the column space. The rest: nullspace and left nullspace. Rank = number of nonzero σ's.
  • Singular values are not the eigenvalues in general. For a symmetric positive definite matrix, they are the same.

Chapter 7. Linear Transformations

7.1 The Idea of a Linear Transformation (LA25, LA15)

  • T is linear when T(cv + dw) = cT(v) + dT(w) for all v, w, c, d. Then T(0) = 0. [HIGH: official example]
  • Linear examples: rotation, projection, reflection, d/dx, integration from 0 to x, any T(v) = Av.
  • Not linear: a shift T(v) = v + a (a ≠ 0), T(v) = ||v||, T(v) = v1 v2, any constant nonzero output.
  • Kernel (nullspace) of T and range (image) of T.

7.2 The Matrix of a Linear Transformation (LA25)

  • Choose input basis v1, ..., vn and output basis w1, ..., wm. Column j of the matrix = the coefficients of T(v_j) in the w's.
  • Composition ST corresponds to the matrix product (matrix of S) times (matrix of T).
  • Change of basis: if the columns of M are the new basis vectors written in the old basis, the matrix of T in the new basis is M^-1 A M (similar to A).
  • Example: d/dx on polynomials of degree ≤ 3 (basis 1, x, x^2, x^3) to degree ≤ 2: [0 1 0 0; 0 0 2 0; 0 0 0 3].

7.3 Diagonalization and the Pseudoinverse

  • Using the eigenvector basis, the matrix of T is diagonal (Λ). Using the singular vector bases (v's in, u's out), it is Σ.
  • Pseudoinverse A^+ = V Σ^+ U^T (Σ^+ has 1/σ_i for nonzero σ_i). A^+ = A^-1 when A is invertible. A^+ A projects onto the row space, A A^+ onto the column space.

Linear algebra in one table (my version of Strang's "Linear Algebra in a Nutshell", 5th ed. sample page)

For an n by n matrix A, all items in one column go together:

Nonsingular (invertible) Singular
columns independent, rows independent columns dependent, rows dependent
det A ≠ 0 det A = 0
Ax = 0 has only x = 0 Ax = 0 has infinitely many solutions
Ax = b has exactly one solution x = A^-1 b Ax = b has no solution or infinitely many
n pivots, rank n, R = I r < n pivots, R has a zero row

Strang's "six great theorems" (5th ed. sample page): every basis of a space has the same size (dimension); dim C(A) + dim N(A) = number of columns (counting); dim C(A) = dim C(A^T) (rank); row space and nullspace are orthogonal complements (fundamental theorem); orthonormal v's and u's with A v_i = σ_i u_i (SVD); symmetric A = Q Λ Q^T (spectral).

Part B. Lang, A First Course in Calculus, 5th ed., Ch. 1 to 15

Chapter I. Numbers and Functions

§1 Integers, rational numbers and real numbers

  • Integers, rationals p/q, reals. Know a proof that √2 is irrational (assume √2 = p/q in lowest terms, then p^2 = 2q^2 forces p and then q to be even, a contradiction).

§2 Inequalities (C1)

  • Multiplying an inequality by a negative number reverses it.
  • |x| = √(x^2). |x - a| < c means a - c < x < a + c. |a + b| ≤ |a| + |b|.

§3 Functions

  • Function, domain, range, value. Even f(-x) = f(x), odd f(-x) = -f(x).

§4 Powers

  • a^(m/n) = (n-th root of a)^m for a > 0. a^x a^y = a^(x+y), (a^x)^y = a^(xy), a^(-x) = 1/a^x, a^0 = 1.

Chapter II. Graphs and Curves (C1)

  • §1 to §2 Coordinates and the graph of a function.
  • §3 Line: slope m = (y2 - y1)/(x2 - x1). y - y1 = m(x - x1), or y = mx + b. Perpendicular slopes: m1 m2 = -1.
  • §4 Distance between two points: √((x2 - x1)^2 + (y2 - y1)^2).
  • §5 Curves and equations: a point is on the curve when it satisfies the equation.
  • §6 Circle: (x - a)^2 + (y - b)^2 = r^2. Complete the square to find the centre and radius.
  • §7 Ellipse: x^2/a^2 + y^2/b^2 = 1 (a dilation of the unit circle).
  • §8 Parabola: y = ax^2 + bx + c, vertex at x = -b/(2a).
  • §9 Hyperbola: x^2/a^2 - y^2/b^2 = 1, vertices (±a, 0), asymptotes y = ±(b/a)x. Also xy = c. [HIGH: reported 2025]

Chapter III. The Derivative (C2, C3, C5 to C8)

  • §1 to §2 Derivative: f'(x) = lim_{h→0} (f(x + h) - f(x))/h (Newton quotient). It is the slope of the tangent line. [HIGH]
  • Tangent line at x = a: y = f(a) + f'(a)(x - a). Normal line slope: -1/f'(a). [HIGH]
  • §3 Limits: limits of sums, products and quotients (nonzero denominator) are sums, products and quotients of limits.
  • §4 (x^n)' = n x^(n-1) (later for any real exponent).
  • §5 (f + g)' = f' + g'. (fg)' = f'g + fg'. (f/g)' = (f'g - fg')/g^2.
  • §6 Chain rule: (f(g(x)))' = f'(g(x)) g'(x).
  • §7 Higher derivatives f'', f''', f^(n).
  • §8 Implicit differentiation: differentiate both sides, treat y as y(x), then solve for y'. [HIGH: reported 2017]
  • §9 Rate of change (related rates): find the relation, differentiate in t, then substitute the numbers.
  • Differentiable at a point implies continuous there, not the other way (|x| at 0).

Chapter IV. Sine and Cosine (C4 to C6)

  • §0 Radians: π rad = 180 degrees. Arc length s = rθ. Sector area r^2 θ/2.
  • §1 Definitions on the unit circle. sin^2 x + cos^2 x = 1. sin(-x) = -sin x, cos(-x) = cos x. tan = sin/cos.
  • Values at 0, π/6, π/4, π/3, π/2 (table in the formula sheet below). [HIGH]
  • §2 Graphs of sin, cos (period 2π), tan (period π, asymptotes at π/2 + kπ).
  • §3 Addition formulas: sin(x + y) = sin x cos y + cos x sin y. cos(x + y) = cos x cos y - sin x sin y. Double angle: sin 2x = 2 sin x cos x, cos 2x = cos^2 x - sin^2 x = 1 - 2sin^2 x = 2cos^2 x - 1. Triple angle: sin 3x = 3 sin x - 4 sin^3 x, cos 3x = 4cos^3 x - 3cos x. [HIGH: reported 2021]
  • §4 (sin x)' = cos x, (cos x)' = -sin x, (tan x)' = 1/cos^2 x = 1 + tan^2 x.
  • §5 Two basic limits: lim_{h→0} (sin h)/h = 1 and lim_{h→0} (cos h - 1)/h = 0. Also (1 - cos x)/x^2 → 1/2. [HIGH: official example]
  • §6 Polar coordinates: x = r cos θ, y = r sin θ, r = √(x^2 + y^2), tan θ = y/x.

Chapter V. The Mean Value Theorem (C9)

  • §1 Max-min theorem: a continuous function on a closed bounded interval [a, b] has a maximum and a minimum. They occur at critical points (f'(c) = 0 or f' does not exist) or at the endpoints.
  • At an interior max or min where f is differentiable, f'(c) = 0.
  • §2 f' > 0 on an interval: f is increasing. f' < 0: decreasing.
  • §3 Rolle's theorem: if f is continuous on [a, b], differentiable on (a, b), and f(a) = f(b), then f'(c) = 0 for some c in (a, b). (Without the hypotheses it fails: f(x) = |x| on [-1, 1].) Mean value theorem: f continuous on [a, b], differentiable on (a, b), then f'(c) = (f(b) - f(a))/(b - a) for some c in (a, b). [HIGH]
  • Consequences: f' = 0 on an interval means f is constant. Two functions with the same derivative differ by a constant.

Chapter VI. Sketching Curves (C10, C11)

  • §1 Behaviour as x → ±∞ (the dominant term of a polynomial wins). Horizontal asymptotes.
  • §2 Concavity: f'' > 0 bends up (convex), f'' < 0 bends down. Inflection point: where f'' changes sign.
  • Second derivative test: f'(c) = 0 and f''(c) < 0 gives a local max; f''(c) > 0 a local min.
  • §3 Cubic polynomials: f' is a quadratic, so there are two, one or zero critical points (discriminant of f' > 0, = 0, < 0). Example with one: y = x^3 (flat inflection at 0).
  • §4 Rational functions: vertical asymptotes where the denominator is 0 (and the top is not), oblique asymptotes by polynomial division.
  • Sketching checklist: domain, intercepts, sign, symmetry, asymptotes, f' table (increase and decrease), f'' table (bending), key points, then draw. [HIGH: reported 2011, 2021]
  • §5 Applied max and min: name variables, write the constraint, reduce to one variable, find critical points, check the ends of the allowed interval. [HIGH: reported 2024]

Chapter VII. Inverse Functions (C12)

  • §1 A strictly increasing (or decreasing) continuous function has an inverse. Its graph is the mirror image in y = x.
  • §2 (f^-1)'(y) = 1/f'(x) where y = f(x).
  • §3 arcsin: [-1, 1] → [-π/2, π/2], (arcsin x)' = 1/√(1 - x^2).
  • §4 arctan: all reals → (-π/2, π/2), (arctan x)' = 1/(1 + x^2). arctan x → ±π/2 as x → ±∞.

Chapter VIII. Exponents and Logarithms (C13)

  • §1 (e^x)' = e^x, e^0 = 1, e^(x + y) = e^x e^y, e^x > 0.
  • §2 log is the inverse of exp (natural log). log(xy) = log x + log y, log(x^a) = a log x, (log x)' = 1/x, and (log |x|)' = 1/x.
  • §3 a^x = e^(x log a), (a^x)' = a^x log a. (x^a)' = a x^(a-1) for any real a. Log differentiation for x^x: (x^x)' = x^x (log x + 1).
  • §4 y' = Ky gives y = C e^(Kx). Growth and decay, half-life (log 2)/|K|.
  • §5 Order of magnitude: as x → ∞, x^n/e^x → 0 and (log x)/x^a → 0 for a > 0. As x → 0+, x^a log x → 0 for a > 0.
  • §6 log x = ∫_1^x dt/t (area under 1/x).
  • e = lim (1 + 1/n)^n ≈ 2.718 (standard fact, useful in follow-ups).

Chapter IX. Integration (C14)

  • §1 Indefinite integral: F is an antiderivative of f when F' = f. ∫ f dx = F + C.
  • §2 Continuous function: lim_{x→a} f(x) = f(a). Sums, products, quotients and compositions of continuous functions are continuous. Intermediate value theorem (state it).
  • §3 to §4 Area under a curve defined with upper and lower sums. A continuous function on [a, b] is integrable.
  • §5 Fundamental theorem: (1) F(x) = ∫_a^x f(t) dt has F' = f (f continuous). (2) ∫_a^b f(x) dx = G(b) - G(a) for any antiderivative G. [HIGH]

Chapter X. Properties of the Integral (C14, C20)

  • §1 d/dx ∫_a^(g(x)) f(t) dt = f(g(x)) g'(x).
  • Linearity, ∫_a^b + ∫_b^c = ∫_a^c, ∫_b^a = -∫_a^b.
  • §2 Riemann sums: Σ f(c_i) Δx → ∫_a^b f. Use this to turn a limit of a sum into an integral, e.g. (1/n) Σ f(k/n) → ∫_0^1 f.
  • Useful sums: 1 + 2 + ... + n = n(n + 1)/2, 1^2 + ... + n^2 = n(n + 1)(2n + 1)/6.
  • §3 Inequalities: f ≤ g on [a, b] gives ∫ f ≤ ∫ g. |∫ f| ≤ ∫ |f|. Mean value theorem for integrals: if f is continuous on [a, b], then ∫_a^b f = f(c)(b - a) for some c in [a, b].
  • §4 Improper integrals: a limit. ∫_1^∞ dx/x^p converges exactly when p > 1. ∫_0^1 dx/x^p converges exactly when p < 1. Comparison test. Check for blow-ups inside the interval. [HIGH]

Chapter XI. Techniques of Integration (C15 to C18)

  • §1 Substitution: ∫ f(g(x)) g'(x) dx = ∫ f(u) du. For definite integrals, change the limits. [HIGH: the most common analysis type]
  • §2 Integration by parts: ∫ u dv = uv - ∫ v du. Twice for e^x sin x (solve for I). Choose u = log or inverse trig first, then powers. [HIGH]
  • §3 Trig integrals: sin^2 x = (1 - cos 2x)/2, cos^2 x = (1 + cos 2x)/2. Odd powers: save one factor. Trig substitution: √(a^2 - x^2) with x = a sin θ, √(a^2 + x^2) with x = a tan θ.
  • §4 Partial fractions: divide first if deg(top) ≥ deg(bottom). Linear factors A/(x - a), repeated factors A/(x - a) + B/(x - a)^2, quadratic factors give arctan. Cover-up method.
  • §5 Exponential substitutions: u = e^x. Example: ∫ dx/(1 + e^x) = x - log(1 + e^x) + C.
  • Symmetry tricks: odd function on [-a, a] gives 0. x → π - x on [0, π] (C18).

Chapter XII. Applications of Integration (C19)

  • Area between curves: ∫ (top - bottom) dx between the intersection points.
  • §1 Volume of revolution about the x-axis: disks V = π ∫ f(x)^2 dx. Washers: π ∫ (R^2 - r^2) dx. Shells about the y-axis: V = 2π ∫ x f(x) dx.
  • §2 Area in polar coordinates: A = (1/2) ∫ r^2 dθ.
  • §3 Length of a curve: L = ∫ √(1 + f'(x)^2) dx.
  • §4 Parametric curves: L = ∫ √(x'(t)^2 + y'(t)^2) dt. Slope dy/dx = y'(t)/x'(t).
  • §5 Surface of revolution: S = 2π ∫ f(x) √(1 + f'(x)^2) dx.
  • §6 Work: W = ∫ F(x) dx.
  • §7 Moments and centre of gravity: for the region under y = f(x), x̄ = ∫ x f(x) dx / ∫ f(x) dx and ȳ = (1/2) ∫ f(x)^2 dx / ∫ f(x) dx.

Chapter XIII. Taylor's Formula (C2, C21)

  • §1 Taylor's formula: f(x) = f(a) + f'(a)(x - a) + f''(a)(x - a)^2/2! + ... + f^(n-1)(a)(x - a)^(n-1)/(n - 1)! + R_n. [HIGH]
  • §2 Remainder (Lagrange form): R_n = f^(n)(c)(x - a)^n/n! for some c between a and x. Bound it with the largest value of |f^(n)|. (Check how your copy of Lang numbers the remainder; the idea is the same.)
  • §3 to §7 The five series to know by heart (centre 0):
    • sin x = x - x^3/3! + x^5/5! - ...
    • cos x = 1 - x^2/2! + x^4/4! - ...
    • e^x = 1 + x + x^2/2! + x^3/3! + ...
    • log(1 + x) = x - x^2/2 + x^3/3 - ... (-1 < x ≤ 1)
    • arctan x = x - x^3/3 + x^5/5 - ... (|x| ≤ 1)
    • (1 + x)^a = 1 + a x + a(a - 1) x^2/2! + ... (|x| < 1)
  • §8 Limits with Taylor: replace each function by its first terms. L'Hôpital's rule (not a separate section in Lang's table of contents, but in the free books): for 0/0 or ∞/∞, lim f/g = lim f'/g' when the right side exists. [HIGH: reported 2017, 2022]
  • "1 to the ∞" forms: take the log first (C2).

Chapter XIV. Series (C22, C23)

  • §1 Convergent series: the partial sums S_N have a limit. Geometric: Σ_{n≥0} r^n = 1/(1 - r) for |r| < 1. If Σ a_n converges, then a_n → 0 (not the converse). [HIGH]
  • §2 Positive terms: converges exactly when the partial sums are bounded. Comparison test. Limit comparison.
  • p-series: Σ 1/n^p converges exactly when p > 1. Harmonic series Σ 1/n diverges.
  • §3 Ratio test: |a_(n+1)/a_n| → L. L < 1 converges absolutely, L > 1 diverges, L = 1 no information.
  • §4 Integral test: for positive decreasing f, Σ f(n) and ∫_1^∞ f(x) dx converge or diverge together.
  • §5 Absolute convergence implies convergence. Alternating series test: if a_n decreases to 0, Σ (-1)^n a_n converges.
  • §6 Power series Σ a_n x^n: there is a radius of convergence R. It converges absolutely for |x| < R and diverges for |x| > R. Check the endpoints separately.
  • §7 Inside the radius you may differentiate and integrate term by term, with the same radius. Example: Σ n x^n = x/(1 - x)^2.

Appendix. ε and δ (between Ch. XIV and XV)

  • §1 Least upper bound: every nonempty set of reals that is bounded above has a least upper bound.
  • §2 Limit: lim_{x→a} f(x) = L when for every ε > 0 there is δ > 0 such that 0 < |x - a| < δ implies |f(x) - L| < ε.
  • §3 Points of accumulation (a point a with points of the set arbitrarily close to it, other than a).
  • §4 Continuous functions on closed bounded intervals are bounded and reach their max and min.

Chapter XV. Vectors (C24, also Strang Ch. 1)

  • §1 Points in n-space, addition, multiplication by numbers.
  • §2 Located vectors (from P to Q is Q - P). Parallel when one is a multiple of the other.
  • §3 Scalar product A·B. Perpendicular when A·B = 0.
  • §4 Norm ||A|| = √(A·A). Distance ||A - B||. Unit vector A/||A||. Projection of A along B: (A·B / B·B) B. Schwarz |A·B| ≤ ||A|| ||B||. Triangle ||A + B|| ≤ ||A|| + ||B||. cos θ = A·B/(||A|| ||B||).
  • §5 Parametric line through P in direction A: X = P + tA. Through P and Q: X = P + t(Q - P).
  • §6 Plane through P with normal N: N·(X - P) = 0, i.e. ax + by + cz = d with N = (a, b, c). Distance from Q to the plane = |aQ1 + bQ2 + cQ3 - d|/||N||. Angle between planes = angle between normals.

Extra (outside the chapter titles, but asked before): differential equations (C25)

  • y' = ky: y = Ce^(kx) (this one is in Lang VIII §4).
  • Lower priority: separable equations, g(y) dy = h(x) dx, integrate both sides. Outside both set books, asked only in an old 2011 exam.
  • a y'' + b y' + c y = 0: characteristic equation a r^2 + b r + c = 0.
    • two real roots r1, r2: y = A e^(r1 x) + B e^(r2 x)
    • repeated root r: y = (A + Bx) e^(rx)
    • complex roots α ± iβ: y = e^(αx)(A cos βx + B sin βx)
  • Use the initial conditions to find A and B.

Linear algebra facts to say in one breath

  • Rank r: dim C(A) = dim C(A^T) = r, dim N(A) = n - r, dim N(A^T) = m - r.
  • Projection: P = A(A^T A)^-1 A^T, P^2 = P = P^T. Normal equations A^T A x̂ = A^T b.
  • det(AB) = det A det B, det A^T = det A, det A^-1 = 1/det A, det(cA) = c^n det A.
  • Trace = sum of eigenvalues, det = product. A = SΛS^-1, A^k = SΛ^kS^-1. Symmetric: A = QΛQ^T.
  • Positive definite (symmetric): pivots, upper-left dets, eigenvalues all > 0; x^T A x > 0.
  • SVD: A = UΣV^T, σ^2 = eigenvalues of A^T A.
  • Linear: T(cv + dw) = cT(v) + dT(w), so T(0) = 0.
